# 用户资料 API

接口统一前缀：`/api`。以下接口均需要 `auth:api` Bearer Token，并使用统一响应
格式。

## 编辑用户资料

`PATCH /api/user`

请求参数均为可选，仅更新提交的字段：

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| real_name | string/null | 真实姓名，最长 255 字符 |
| nick_name | string/null | 昵称，最长 50 字符 |
| avatar | string/null | 头像地址或文件路径，最长 2048 字符 |
| gender | integer/null | `0` 未知、`1` 男、`2` 女 |
| email | string/null | 邮箱 |

`phone` 和 `status` 不允许通过该接口修改。

请求示例：

```json
{
  "real_name": "张三",
  "nick_name": "小张",
  "avatar": "avatars/zhang-san.png",
  "gender": 1,
  "email": "zhangsan@example.com"
}
```

成功响应：

```json
{
  "code": 200,
  "data": {
    "message": "用户信息更新成功",
    "user": {
      "id": 1,
      "uuid": "019c12ef-9067-7b9d-8432-7cd97c58e295",
      "real_name": "张三",
      "nick_name": "小张",
      "phone": "13800138000",
      "avatar": "avatars/zhang-san.png",
      "gender": 1,
      "email": "zhangsan@example.com",
      "status": 1,
      "created_at": "2026-07-31T08:00:00.000000Z",
      "updated_at": "2026-07-31T08:10:00.000000Z"
    }
  },
  "meta": {
    "timestamp": 1785485400.123,
    "response_time": 0.018
  }
}
```

提交 `phone` 或 `status` 时返回 HTTP `422`：

```json
{
  "code": 422,
  "message": "The given data was invalid.",
  "errors": {
    "phone": [
      "phone 字段被禁止。"
    ]
  }
}
```

## 发送修改手机号验证码

`POST /api/user/phone/sms-code`

请求示例：

```json
{
  "phone": "13900139000"
}
```

成功响应：

```json
{
  "code": 200,
  "data": {
    "message": "验证码发送成功",
    "expires_in": 300
  },
  "meta": {
    "timestamp": 1785485400.123,
    "response_time": 0.012
  }
}
```

新手机号不能与当前手机号相同，也不能已被其他用户使用。验证码有效期为 5 分钟，
同一客户端每分钟最多发送一次。

手机号已被使用时返回 HTTP `422`：

```json
{
  "code": 422,
  "message": "The given data was invalid.",
  "errors": {
    "phone": [
      "该手机号已被其他用户使用"
    ]
  }
}
```

## 确认修改手机号

`PATCH /api/user/phone`

请求示例：

```json
{
  "phone": "13900139000",
  "code": "123456"
}
```

成功响应：

```json
{
  "code": 200,
  "data": {
    "message": "手机号修改成功",
    "user": {
      "id": 1,
      "uuid": "019c12ef-9067-7b9d-8432-7cd97c58e295",
      "real_name": "张三",
      "nick_name": "小张",
      "phone": "13900139000",
      "avatar": "avatars/zhang-san.png",
      "gender": 1,
      "email": "zhangsan@example.com",
      "status": 1,
      "created_at": "2026-07-31T08:00:00.000000Z",
      "updated_at": "2026-07-31T08:20:00.000000Z"
    }
  },
  "meta": {
    "timestamp": 1785486000.123,
    "response_time": 0.021
  }
}
```

验证码错误或过期时返回 HTTP `422`：

```json
{
  "code": 422,
  "message": "The given data was invalid.",
  "errors": {
    "code": [
      "验证码错误或已过期"
    ]
  }
}
```

验证码与用户 ID、新手机号绑定，不能用于其他用户、其他手机号或登录流程，验证
成功后立即失效。
