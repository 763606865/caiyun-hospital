# 医院公开信息 API

接口统一前缀：`/api`  
响应格式见 [响应格式](./响应格式.md)。  
**无需登录。**

一期为本地挂号闭环（`hs_*` 表）。后续对接 HIS 时，建议在预约单/号源上扩展外部单号字段，接口形态可保持稳定。

相关文档：[就诊人](./就诊人.md)、[挂号预约](./挂号预约.md)、[患者端概览](./患者端概览.md)

## 首页聚合

`GET /api/hospital/home`

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| campus | string | 否 | 院区 slug，用于过滤常挂科室 |

返回：`campuses`、`featured_departments`（常挂）、`notices`（CMS `notices`/`suspensions`）、`latest_suspension`。

登录后的「默认就诊人 / 今日待就诊」见 [患者端概览](./患者端概览.md)。

## 院区列表

`GET /api/hospital/campuses`

## 院区详情

`GET /api/hospital/campuses/{slug}`

## 科室分类

`GET /api/hospital/department-categories`

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| campus | string | 否 | 院区 slug；传入时 `department_count` 仅统计该院区科室 |

返回示例：`[{ "id": 1, "name": "内科系", "slug": "internal", "department_count": 5 }, ...]`。

分类在后台「医院主数据 → 科室分类」维护。

## 科室列表

`GET /api/hospital/departments`

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| campus | string | 否 | 院区 slug |
| category | string | 否 | 科室分类 **slug**（如 `internal`） |
| featured | bool | 否 | 是否仅常挂 |
| q | string | 否 | 关键词 |
| with_today_remaining | bool | 否 | 附带今日余号 |
| per_page | int | 否 | 默认 20 |

科室对象含关联 `category: { id, name, slug }`。

`with_today_remaining=1` 时额外返回 `today_remaining`、`today_status`（`available`/`full`/`none`）。

## 科室详情

`GET /api/hospital/departments/{slug}`

`location` 用于诊室位置文案。

## 医生列表

`GET /api/hospital/doctors`

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| department | string | 否 | 科室 slug |
| campus | string | 否 | 院区 slug |
| visit_type | string | 否 | `normal` / `expert` |
| q | string | 否 | 关键词 |
| with_today_schedule | bool | 否 | 附带今日出诊摘要 |
| per_page | int | 否 | 默认 20 |

`with_today_schedule=1` 时额外返回 `today_remaining`、`today_status`、`today_time_range`、`schedules`。

## 医生详情

`GET /api/hospital/doctors/{slug}`

## 可约排班列表

`GET /api/hospital/schedules`

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| doctor / department / campus | string | 否 | slug 筛选 |
| visit_type | string | 否 | `normal` / `expert` |
| date_from / date_to | date | 否 | 默认今天至放号天数 |
| per_page | int | 否 | 默认 30 |

排班含 `visit_type`、`room`。枚举见 [挂号预约](./挂号预约.md#状态枚举)。

## 排班详情

`GET /api/hospital/schedules/{id}`

## 预约规则（公开）

`GET /api/hospital/appointment-settings`
