# 医院公开信息 API

接口统一前缀：`/api`  
响应格式见 [响应格式](./响应格式.md)。  
**无需登录。**

一期为本地挂号闭环（`hs_*` 表）。后续对接 HIS 时，建议在预约单/号源上扩展外部单号字段，接口形态可保持稳定。

相关文档：[就诊人](./就诊人.md)、[挂号预约](./挂号预约.md)

## 院区列表

`GET /api/hospital/campuses`

返回已启用院区。

## 院区详情

`GET /api/hospital/campuses/{slug}`

## 科室列表

`GET /api/hospital/departments`

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| campus | string | 否 | 院区 slug |
| q | string | 否 | 名称/擅长/简介关键词 |
| per_page | int | 否 | 默认 20，最大 100 |

## 科室详情

`GET /api/hospital/departments/{slug}`

含所属院区、已启用医生列表。

## 医生列表

`GET /api/hospital/doctors`

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| department | string | 否 | 科室 slug |
| campus | string | 否 | 院区 slug |
| q | string | 否 | 姓名/职称/擅长关键词 |
| per_page | int | 否 | 默认 20，最大 100 |

## 医生详情

`GET /api/hospital/doctors/{slug}`

含所属科室。

## 可约排班列表

`GET /api/hospital/schedules`

仅返回状态为正常出诊（`normal`）的排班，并附带可约号源时段。

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| doctor | string | 否 | 医生 slug |
| department | string | 否 | 科室 slug |
| campus | string | 否 | 院区 slug |
| date_from | date | 否 | 默认今天 |
| date_to | date | 否 | 默认今天 + 预约规则提前天数 |
| per_page | int | 否 | 默认 30，最大 100 |

排班 `status`、午别 `period` 枚举见 [挂号预约 · 状态枚举](./挂号预约.md#状态枚举)。

## 排班详情

`GET /api/hospital/schedules/{id}`

## 预约规则（公开）

`GET /api/hospital/appointment-settings`

示例：

```json
{
  "code": 200,
  "data": {
    "registration_enabled": true,
    "advance_days": 7,
    "cancel_hours_before": 2,
    "no_show_limit": 3,
    "no_show_ban_days": 30,
    "notice": "请提前15分钟到院取号"
  }
}
```
