# 就诊人 API

接口统一前缀：`/api`  
响应格式见 [响应格式](./响应格式.md)。  
需登录，鉴权见 [认证](./认证.md)（`Authorization: Bearer {access_token}`）。

仅可操作当前用户名下的就诊人。

## 就诊人列表

`GET /api/patients`

默认就诊人靠前。每条含 `is_minor`（由生日推算，未填生日为 `false`）。

## 新增就诊人

`POST /api/patients`

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| name | string | 是 | 姓名 |
| id_type | string | 否 | 默认 `id_card` |
| id_number | string | 是 | 证件号；同一用户下同证件类型唯一 |
| phone | string | 是 | 手机号 |
| gender | int | 否 | `0`未知 / `1`男 / `2`女 |
| birthday | date | 否 | 出生日期 |
| relation | string | 否 | `self`/`parent`/`child`/`spouse`/`other` |
| is_default | bool | 否 | 是否默认就诊人 |

首个就诊人会自动设为默认。成功返回 `201`。

## 就诊人详情

`GET /api/patients/{id}`

## 更新就诊人

`PATCH /api/patients/{id}`

字段同新增，均为可选。设为默认时会取消其他就诊人的默认标记。

## 删除就诊人

`DELETE /api/patients/{id}`

软删除。
