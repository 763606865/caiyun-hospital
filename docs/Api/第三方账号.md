# 第三方账号 API

接口统一前缀：`/api`。

## 微信小程序手机号登录

`POST /api/auth/wechat/login`

该接口同时完成微信身份校验、微信手机号获取、用户注册/匹配、第三方账号绑定和
Sanctum token 签发。**手机号是必需信息**，服务端只接受微信
`getPhoneNumber` 返回的 `phone_code`，再调用微信接口获取手机号；不接受客户端
直接传入 `mobile`。

服务端环境变量：

```dotenv
WECHAT_MINI_PROGRAM_APP_ID=微信小程序AppID
WECHAT_MINI_PROGRAM_APP_SECRET=微信小程序AppSecret
```

小程序端调用顺序：

1. 调用 `wx.login()` 获取 `login_code`。
2. 用户点击手机号授权按钮，从 `getPhoneNumber` 事件获取 `phone_code`。
3. 将两个 code 一次性提交到本接口。code 只能使用一次，失败后应重新获取。

请求参数：

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| login_code | string | 是 | `wx.login()` 返回的临时 code |
| phone_code | string | 是 | `getPhoneNumber` 返回的手机号动态 code |
| device_name | string | 否 | token 设备名，默认 `wechat-mini-program` |

请求示例：

```json
{
  "login_code": "0a-login-code",
  "phone_code": "0b-phone-code",
  "device_name": "微信小程序"
}
```

无法取得手机号、code 失效、微信账号与已绑定手机号不一致时返回 HTTP `422`。
请求缺少 `phone_code` 同样返回 `422`，不会创建用户或第三方账号。

错误响应示例：

```json
{
  "code": 422,
  "message": "The given data was invalid.",
  "errors": {
    "login_code": [
      "未能获取微信手机号，请重新授权"
    ]
  }
}
```

> `access_token`、`session_key`、AppSecret 等敏感信息不会写入
> `user_accounts.data`，也不会通过 API 返回。

## 表结构扩展约定

- `provider` 使用稳定的小写标识，例如 `wechat`、`alipay`、`douyin`。
- `app_id` 区分同一平台的不同应用。
- `provider_account_id` 保存平台账号唯一标识，例如微信 `openid`。
- `union_id` 保存可选的跨应用统一标识，例如微信 `unionid`。
- `data` 只保存非敏感扩展资料，不保存 access token、refresh token、session key
  或平台密钥。
