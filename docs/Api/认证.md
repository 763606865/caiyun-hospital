# API 认证

接口统一前缀：`/api`

## 发送登录短信验证码

`POST /api/auth/sms-code`

请求参数：

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| phone | string | 是 | 中国大陆手机号 |

请求示例：

```json
{
  "phone": "13800138000"
}
```

成功响应：

```json
{
  "code": 200,
  "data": {
    "message": "验证码发送成功",
    "expires_in": 300
  },
  "meta": {
    "timestamp": 1785484800.123,
    "response_time": 0.012
  }
}
```

同一客户端每分钟最多请求一次。短信通过统一的 `Caiyun\Sms\Contracts\SmsSender` 接口发送；本地默认使用 `log` 驱动，可通过 `SMS_DRIVER` 切换短信服务商。

## 短信登录

`POST /api/auth/login`

验证码有效期为 5 分钟，验证后立即失效。手机号未注册时会自动创建 User 记录。

请求参数：

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| phone | string | 是 | 中国大陆手机号 |
| code | string | 是 | 6 位短信验证码 |
| device_name | string | 否 | token 对应的设备名称，默认 `api` |

请求示例：

```json
{
  "phone": "13800138000",
  "code": "123456",
  "device_name": "iPhone"
}
```

成功响应：

```json
{
  "code": 200,
  "data": {
    "token_type": "Bearer",
    "access_token": "1|xxxxxxxxxxxxxxxx",
    "user": {
      "id": 1,
      "uuid": "019c12ef-9067-7b9d-8432-7cd97c58e295",
      "real_name": null,
      "nick_name": "用户8000",
      "phone": "13800138000",
      "avatar": null,
      "gender": 0,
      "status": 1,
      "created_at": "2026-07-30T08:00:00.000000Z",
      "updated_at": "2026-07-30T08:00:00.000000Z"
    }
  },
  "meta": {
    "timestamp": 1785484800.123,
    "response_time": 0.024
  }
}
```

验证码错误或过期时返回 `422`：

```json
{
  "code": 422,
  "message": "验证码错误或已过期",
  "errors": {
    "code": [
      "验证码错误或已过期"
    ]
  }
}
```

## 微信小程序手机号登录

`POST /api/auth/wechat/login`

该接口同时完成微信身份校验、微信手机号获取、用户注册/匹配、第三方账号绑定和
Sanctum token 签发。**手机号是必需信息**，服务端只接受微信
`getPhoneNumber` 返回的 `phone_code`，再调用微信接口获取手机号；不接受客户端
直接传入 `mobile`。

小程序端调用顺序：

1. 调用 `wx.login()` 获取 `login_code`。
2. 用户点击手机号授权按钮，从 `getPhoneNumber` 事件获取 `phone_code`。
3. 将两个 code 一次性提交到本接口。code 只能使用一次，失败后应重新获取。

请求参数：

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| login_code | string | 是 | `wx.login()` 返回的临时 code |
| phone_code | string | 是 | `getPhoneNumber` 返回的手机号动态 code |
| device_name | string | 否 | token 设备名，默认 `wechat-mini-program` |

请求示例：

```json
{
  "login_code": "0a-login-code",
  "phone_code": "0b-phone-code",
  "device_name": "微信小程序"
}
```

成功响应：

```json
{
  "code": 200,
  "data": {
    "token_type": "Bearer",
    "access_token": "1|xxxxxxxxxxxxxxxx",
    "user": {
      "id": 1,
      "uuid": "019c12ef-9067-7b9d-8432-7cd97c58e295",

      "gender": 0,
      "status": 1,

    },
    "account": {
      "id": 1,
      "provider": "wechat",
      "app_id": "wx123456",
      "mobile": "13800138000",
      "nickname": null,
      "avatar_url": null,
      "last_login_at": "2026-07-31T08:00:00.000000Z"
    }
  },
  "meta": {
    "timestamp": 1785484800.123,

  }
}
```

## 获取当前用户

`GET /api/me`

请求头：

```text
Authorization: Bearer {access_token}
Accept: application/json
```

成功响应：

```json
{
  "code": 200,
  "data": {
    "user": {
      "id": 1,
      "uuid": "019c12ef-9067-7b9d-8432-7cd97c58e295",
      "real_name": null,
      "nick_name": "用户8000",
      "phone": "13800138000",
      "avatar": null,
      "gender": 0,
      "status": 1,
      "created_at": "2026-07-30T08:00:00.000000Z",
      "updated_at": "2026-07-30T08:00:00.000000Z"
    }
  },
  "meta": {
    "timestamp": 1785484800.123,
    "response_time": 0.008
  }
}
```

token 缺失或无效时返回 `401`：

```json
{
  "code": 401,
  "message": "Token expired or invalid."
}
```

## 通用校验错误

参数校验失败时返回 HTTP `422`，错误字段位于 `errors` 对象中。
