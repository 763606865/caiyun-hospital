# API 认证

接口统一前缀：`/api`

## 发送登录短信验证码

`POST /api/auth/sms-code`

请求参数：

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| phone | string | 是 | 中国大陆手机号 |

请求示例：

```json
{
  "phone": "13800138000"
}
```

成功响应：

```json
{
  "message": "验证码发送成功",
  "expires_in": 300
}
```

同一客户端每分钟最多请求一次。短信通过统一的 `Caiyun\Sms\Contracts\SmsSender` 接口发送；本地默认使用 `log` 驱动，可通过 `SMS_DRIVER` 切换短信服务商。

## 短信登录

`POST /api/auth/login`

验证码有效期为 5 分钟，验证后立即失效。手机号未注册时会自动创建 User 记录。

请求参数：

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| phone | string | 是 | 中国大陆手机号 |
| code | string | 是 | 6 位短信验证码 |
| device_name | string | 否 | token 对应的设备名称，默认 `api` |

请求示例：

```json
{
  "phone": "13800138000",
  "code": "123456",
  "device_name": "iPhone"
}
```

成功响应：

```json
{
  "token_type": "Bearer",
  "access_token": "1|xxxxxxxxxxxxxxxx",
  "user": {
    "id": 1,
    "uuid": "019c12ef-9067-7b9d-8432-7cd97c58e295",
    "real_name": null,
    "nick_name": "用户8000",
    "phone": "13800138000",
    "avatar": null,
    "gender": 0,
    "status": 1,
    "created_at": "2026-07-30T08:00:00.000000Z",
    "updated_at": "2026-07-30T08:00:00.000000Z"
  }
}
```

验证码错误或过期时返回 `422`：

```json
{
  "message": "验证码错误或已过期",
  "errors": {
    "code": [
      "验证码错误或已过期"
    ]
  }
}
```

## 获取当前用户

`GET /api/me`

请求头：

```text
Authorization: Bearer {access_token}
Accept: application/json
```

成功响应：

```json
{
  "user": {
    "id": 1,
    "uuid": "019c12ef-9067-7b9d-8432-7cd97c58e295",
    "real_name": null,
    "nick_name": "用户8000",
    "phone": "13800138000",
    "avatar": null,
    "gender": 0,
    "status": 1,
    "created_at": "2026-07-30T08:00:00.000000Z",
    "updated_at": "2026-07-30T08:00:00.000000Z"
  }
}
```

token 缺失或无效时返回 `401`。

## 通用校验错误

参数校验失败时返回 HTTP `422`，错误字段位于 `errors` 对象中。
