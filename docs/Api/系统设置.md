# 系统设置

客户端可通过此接口获取后台维护的当前系统设置。

## 获取系统设置

`GET /api/system/settings`

此接口不要求登录，但需要携带[通用客户端信息请求头](客户端信息.md)。请求参数为空。

成功响应：

```json
{
  "code": 200,
  "data": {
    "site_name": "彩云系统",
    "logo": "https://example.com/storage/system-settings/logo.png",
    "favicon": "https://example.com/storage/system-settings/favicon.ico",
    "customer_service_phone": "400-123-4567",
    "icp_number": "京ICP备12345678号",
    "sms_enabled": true,
    "registration_enabled": true,
    "default_avatar": "https://example.com/storage/system-settings/avatar.png",
    "upload_max_size_mb": 10,
    "payment_enabled": false,
    "maintenance_message": null
  },
  "meta": {
    "timestamp": 1785484800.123,
    "response_time": 0.012
  }
}
```

| 字段 | 类型 | 可空 | 说明 |
| --- | --- | --- | --- |
| site_name | string | 是 | 站点名称；后台尚未创建设置时为 `null` |
| logo | string | 是 | 站点 Logo 的公开访问 URL |
| favicon | string | 是 | 站点 Favicon 的公开访问 URL |
| customer_service_phone | string | 是 | 客服电话 |
| icp_number | string | 是 | ICP 备案号 |
| sms_enabled | boolean | 否 | 是否启用短信功能 |
| registration_enabled | boolean | 否 | 是否开放用户注册 |
| default_avatar | string | 是 | 用户默认头像的公开访问 URL |
| upload_max_size_mb | integer | 否 | 单文件上传大小限制，单位 MB |
| payment_enabled | boolean | 否 | 是否启用支付功能 |
| maintenance_message | string | 是 | 维护模式提示文案 |

后台尚未创建系统设置时，接口仍返回 `200`，布尔开关与上传限制使用系统默认值，其他字段为 `null`。

图片字段由后台保存的文件路径转换为公开 URL；客户端不需要自行拼接域名。
