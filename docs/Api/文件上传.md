# 文件上传

## 上传文件到 OSS

- 请求方式：`POST /api/files/upload`
- 认证方式：`Authorization: Bearer {token}`
- Content-Type：`multipart/form-data`
- 限流：每分钟 30 次

### 请求参数

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `file` | File | 是 | 最大 20 MB；支持 jpg、jpeg、png、gif、webp、pdf、doc、docx、xls、xlsx、zip |
| `directory` | String | 否 | 文件分类：`avatar`、`image`、`document`、`other`，默认 `other` |

文件最终保存路径由服务端生成，格式为：

```text
{directory}/{Y}/{m}/{d}/{uuid}.{extension}
```

### 成功响应

```json
{
    "code": 200,
    "data": {
        "message": "文件上传成功",
        "file": {
            "path": "image/2026/07/31/0198f5ea-71ca-7acb-a105-83da72a1a293.jpg",
            "url": "https://example-bucket.oss-cn-hangzhou.aliyuncs.com/image/2026/07/31/0198f5ea-71ca-7acb-a105-83da72a1a293.jpg",
            "original_name": "photo.jpg",
            "mime_type": "image/jpeg",
            "extension": "jpg",
            "size": 128640
        }
    },
    "meta": {
        "timestamp": 1785484800,
        "response_time": 0.0321
    }
}
```

### 校验失败响应

```json
{
    "code": 422,
    "data": {
        "message": "The file field is required."
    },
    "meta": {
        "timestamp": 1785484800,
        "response_time": 0.0082
    }
}
```
