# 客户端版本校验

客户端通过请求头传递当前版本信息，服务端按照客户端类型、运行平台和发布渠道查找最新的已发布版本。

## 校验版本

`GET /api/client/version/check`

此接口不要求登录，但需要携带通用客户端信息请求头：

```text
X-Client-Type: app-ios
X-App-Version: 1.1.0
X-App-Build: 110
X-Platform: ios
X-OS-Version: 18.2
X-Device-ID: ios-installation-id
X-Channel: app-store
```

成功响应：

```json
{
  "code": 200,
  "data": {
    "has_update": true,
    "force_update": false,
    "update_type": "optional",
    "latest_version": {
      "app_version": "1.2.0",
      "app_build": "120",
      "min_supported_version": "1.0.0",
      "min_supported_build": "100",
      "download_url": "https://example.com/app",
      "release_notes": "修复已知问题",
      "published_at": "2026-07-31T08:00:00.000000Z"
    }
  },
  "meta": {
    "timestamp": 1785484800.123,
    "response_time": 0.012
  }
}
```

`update_type` 可取：

- `none`：当前已是最新版本
- `optional`：存在可选更新
- `force`：后台将目标版本标记为强制更新，或当前版本低于最低支持版本

如果当前客户端类型、平台和渠道没有已发布的版本配置，接口返回 `has_update: false`，且 `latest_version` 为 `null`。

最新版本按照 `published_at` 倒序选取；草稿和尚未到发布时间的版本不会参与校验。

## 最低版本中间件限制

除版本校验接口自身外，所有 API 请求都会由客户端信息中间件检查最低支持版本。当前版本低于后台配置的 `min_supported_version` 或 `min_supported_build` 时，请求返回 HTTP `426 Upgrade Required`：

```json
{
  "code": 426,
  "message": "客户端版本过低，请升级后继续使用"
}
```

可选更新不会阻断 API 请求。版本校验接口始终放行，过低版本的客户端可以继续调用它获取下载地址和更新说明。

最新版本策略默认缓存 300 秒，可通过 `CLIENT_VERSION_CACHE_TTL` 调整。通过 Admin 或 Eloquent 新增、修改、删除客户端版本时，会主动清除对应客户端、平台和渠道的缓存。
