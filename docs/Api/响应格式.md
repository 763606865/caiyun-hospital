# API 统一响应格式

所有 `/api/*` 接口，包括控制器、中间件校验和异常响应，统一使用以下结构。

## 成功响应

```json
{
  "code": 200,
  "data": {
    "user": {
      "id": 1
    }
  },
  "meta": {
    "timestamp": 1785484800.123,
    "response_time": 0.018
  }
}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| code | integer | 与 HTTP 状态码一致 |
| data | object/array | 业务数据，无数据时为空对象或数组 |
| meta.timestamp | float | 服务端生成响应时的 Unix 时间 |
| meta.response_time | float | 服务端处理耗时，单位为秒 |

控制器通过以下方式返回：

```php
return $this->success([
    'user' => $user,
]);
```

## 错误响应

```json
{
  "code": 422,
  "message": "The given data was invalid.",
  "errors": {
    "phone": [
      "手机号格式不正确"
    ]
  }
}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| code | integer | 与 HTTP 状态码一致 |
| message | string | 可展示或记录的错误概要 |
| errors | object | 调试模式下的字段错误或异常详情，可能不存在 |

控制器通过以下方式返回：

```php
return $this->error('请求参数错误', 422, [
    'phone' => ['手机号格式不正确'],
]);
```

以下异常同样会转换为统一错误结构：

- 参数校验错误：`422`
- 未认证：`401`
- 资源不存在：`404`
- 请求频率限制：`429`
- 自定义 `App\Exceptions\HttpException`
- 未处理的服务器异常：`500`

生产环境的 `500` 响应不会暴露异常消息或调用栈。
