患者端医院相关 API 已按模块拆分，请查阅：

| 文档 | 前缀 | 鉴权 |
| --- | --- | --- |
| [医院公开信息](./医院公开信息.md) | `/api/hospital/*` | 否 |
| [患者端概览](./患者端概览.md) | `/api/me/overview` | 是（`auth:api`） |
| [就诊人](./就诊人.md) | `/api/patients/*` | 是（`auth:api`） |
| [挂号预约](./挂号预约.md) | `/api/appointments/*` | 是（`auth:api`） |
| [体检公开信息](./体检公开信息.md) | `/api/hospital/checkup-*` | 否 |
| [体检预约](./体检预约.md) | `/api/checkup-orders/*` | 是（`auth:api`） |
