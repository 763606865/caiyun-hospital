# 患者端概览 API

接口统一前缀：`/api`  
响应格式见 [响应格式](./响应格式.md)。  
需登录，鉴权见 [认证](./认证.md)。

用于首页「今日待就诊」、我的页统计条与默认就诊人。

## 登录态概览

`GET /api/me/overview`

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| patient_id | int | 否 | 切换就诊人；默认取默认就诊人 |
| campus | string | 否 | 过滤今日预约所属院区 |

成功 `data` 主要字段：

| 字段 | 说明 |
| --- | --- |
| user | 含 `is_verified`（已填真实姓名视为已实名） |
| default_patient | 默认就诊人，含 `is_minor` |
| selected_patient | 当前选中就诊人 |
| patients | 全部就诊人 |
| today_appointments | 今日待就诊列表（含医生/科室 `location`/院区坐标/取号 `ticket_no`/凭证 `voucher_code`） |
| stats.pending_appointments | 待就诊数量 |
| stats.patients | 就诊人数量 |
| stats.reports | 报告数（未接 LIS 时固定 `0`） |
| stats.pending_payments | 当前就诊人的待支付数，合并统计挂号与体检预约 |

客服电话继续使用 [系统设置](./系统设置.md) 的 `customer_service_phone`。
