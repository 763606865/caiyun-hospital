# 体检公开信息 API

接口统一前缀：`/api`  
响应格式见 [响应格式](./响应格式.md)。  
**无需登录。**

体检套餐预约为独立业务域（`hs_checkup_*`），与门诊挂号并行。报告查询需对接 LIS/体检系统，本期不做。

相关文档：[体检预约](./体检预约.md)、[就诊人](./就诊人.md)

## 套餐列表

`GET /api/hospital/checkup-packages`

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| campus | string | 否 | 院区 slug |
| q | string | 否 | 名称/简介关键词 |
| per_page | int | 否 | 默认 20，最大 100 |

仅返回已上架套餐，含院区与启用中的检查项目。

## 套餐详情

`GET /api/hospital/checkup-packages/{slug}`

含院区、检查项目列表。

## 可约场次列表

`GET /api/hospital/checkup-slots`

仅返回仍有余量且可约的场次。

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| package | string | 否 | 套餐 slug |
| campus | string | 否 | 院区 slug |
| date_from | date | 否 | 默认今天 |
| date_to | date | 否 | 默认今天 + 体检规则提前天数 |
| per_page | int | 否 | 默认 30，最大 100 |

场次午别 `period`：`morning` / `afternoon` / `evening`。

## 体检预约规则（公开）

`GET /api/hospital/checkup-settings`

示例：

```json
{
  "code": 200,
  "data": {
    "booking_enabled": true,
    "advance_days": 14,
    "cancel_hours_before": 24,
    "no_show_limit": 3,
    "no_show_ban_days": 30,
    "notice": "请空腹到检，带好身份证件"
  }
}
```
