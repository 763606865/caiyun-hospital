# 排班批量生成

门诊排班不靠后台逐条录入，而是：

1. 在后台维护 **出诊周模板**（医生 + 星期 + 午别 + 号源时段）
2. 定时任务 / 命令按 **预约规则提前放号天数** 滚动生成未来窗口内的 `hs_schedules` + `hs_quotas`

## 运营配置

后台路径：**医院主数据 → 医生管理 → 配置 → 出诊模板**

- 在医生配置页维护每周固定出诊（如周一上午专家号）
- 可用「一键生成模板」按普遍门诊时间批量生成周一～周日上/下/晚模板及 30 分钟号源（再按需微调）
- 点「号源时段模板」维护时段（如 09:00-09:30 共 5 号）
- 仅「启用」且所属院区/科室/医生启用的模板会参与生成

## 命令

```bash
# 默认：今天 ~ 今天+advance_days（预约规则，默认 7 天）
php artisan hospital:generate-schedules

# 指定天数（含今天）
php artisan hospital:generate-schedules --days=14

# 指定日期范围
php artisan hospital:generate-schedules --from=2026-09-07 --to=2026-09-20

# 仅预览将新建数量
php artisan hospital:generate-schedules --dry-run
```

已存在的「同医生 + 同科室 + 同日期 + 同午别」排班会跳过，不会覆盖或重复造号。

## 定时任务

`routes/console.php` 已注册：

```php
Schedule::command('hospital:generate-schedules')->dailyAt('00:30');
```

生产环境需保证 Laravel Scheduler 每分钟执行（`* * * * * php artisan schedule:run`）。

每日凌晨补齐窗口：例如 `advance_days=7` 时，始终保证今天起 8 天（今天+7）内模板对应的排班齐全。
